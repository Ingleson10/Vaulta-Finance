Vaulta Finance 🏦 - Full Stack Evolution
Este repositório contém a versão de desenvolvimento do Vaulta Finance, agora integrado com um frontend moderno para gestão financeira pessoal.

🚀 Novidades desta Branch
Frontend Mobile-First: Interface construída com Next.js 15 e Tailwind CSS.

Segurança Avançada: Implementação de autenticação via JWT com armazenamento em Cookies HttpOnly para maior proteção contra ataques XSS.

Dashboard em Tempo Real: Consumo de APIs Spring Boot para exibição de saldos, receitas e despesas.

Tipagem Robusta: Uso estrito de TypeScript em todo o frontend, eliminando inconsistências de dados.

🛠 Tecnologias Adicionais (Frontend)
Next.js: Framework React para alta performance.

Axios: Cliente HTTP para comunicação com a API Java.

Lucide React: Biblioteca de ícones modernos.

🏁 Como Rodar o Projeto
1. Backend (Spring Boot):

Certifique-se de que o PostgreSQL está ativo.

Execute a aplicação via sua IDE (Eclipse/IntelliJ) na porta 8081.

2. Frontend (Next.js):
cd client
npm install
npm run dev

Acesse http://localhost:3000 no seu navegador.
